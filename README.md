# DeKalb Music Scene

Static Next.js site for tracking the DeKalb music scene.

## Routes

- `/about`: Project overview and mission
- `/upcoming-shows`: Upcoming local events
- `/photos`: Scene photo gallery

Legacy routes are still available:

- `/radio`: Compatibility page linking to new sections
- `/schedule`: Compatibility page linking to upcoming shows

## Development

```bash
npm install
npm run dev
```

## Show Data Files

- `data/shows.ts`: Upcoming show cards and metadata
- `data/photos.ts`: Photo gallery data
